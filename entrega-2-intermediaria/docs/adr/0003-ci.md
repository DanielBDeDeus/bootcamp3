# ADR 0003 - GitHub Actions para CI

## Status

Aceito.

## Contexto

A atividade exige test harness automatizado, histórico de execuções e evidência objetiva de qualidade.

## Decisão

Executar `npm test` automaticamente em pushes e Pull Requests.

## Consequências

- Resultado reproduzível.
- Evidência vinculada a commits e PRs.
- Falhas ficam visíveis no histórico.
- O merge deve ocorrer somente após revisão humana e CI aprovado.
