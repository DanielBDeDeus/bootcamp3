# Prompt padrão para comparar agentes de IA

Use o mesmo pedido nas ferramentas realmente avaliadas:

> Analise a função `splitExpense` deste repositório. Identifique um caso de borda capaz de produzir comportamento inválido. Proponha primeiro um teste automatizado e, somente depois, uma correção. Explique o risco de aceitar a mudança sem revisão humana.

Para cada ferramenta, registre:

1. Se identificou corretamente o caso de borda.
2. Se produziu teste executável.
3. Se a correção fez o teste passar.
4. Se introduziu regressões.
5. Se inventou API, arquivo ou comportamento inexistente.
6. Quanto retrabalho humano foi necessário.
7. Principal vantagem e principal limitação observadas.

Não inventar resultados.
