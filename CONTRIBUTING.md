# Guia de contribuição

## Fluxo

1. Trabalhar em branch curta a partir de `main`.
2. Fazer commits pequenos e descritivos.
3. Publicar a branch.
4. Abrir Pull Request.
5. Aguardar o CI.
6. Solicitar revisão de outro integrante.
7. Corrigir apontamentos.
8. Fazer merge somente depois da revisão.

## Branches

- `feature/...`
- `fix/...`
- `docs/...`
- `test/...`

## Commits

- `feat:`
- `fix:`
- `test:`
- `docs:`
- `chore:`
